Project Manpower Indicator

Easily track time and manpower directly from Project Tasks!

Key Features

  • Start/Stop Buttons: Track exact time spent on tasks with intuitive start and stop buttons directly inside the task view.
  • Manpower Logs: Automatically records all time entries in a clean log, attributing them to the active user.
  • Real-Time Tracking: Keeps a record of current ongoing tasks, allowing seamless multi-user collaboration.
  • No Configuration Required: Plug-and-play installation! Install and start tracking immediately.
  • Odoo 17 Ready: Fully tested and compatible with Odoo 17 Enterprise & Community.

Why Choose This Module?

Tracking manpower and hours on project tasks can be tedious. This module simplifies the process by providing one-click Start and Stop buttons. It is perfect for teams that need accurate time logging without navigating away from their active tasks. Increase productivity and billing accuracy instantly!
