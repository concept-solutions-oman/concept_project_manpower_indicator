Easy Installation & Usage

  1. Install the module from the Odoo Apps menu.
  2. Open the Employees module to view the dashboard and floating panel.
  3. Click On Duty via the status indicator to start a work session.
  4. Click Off Duty to end the work session.
  5. Review activity under Reporting → Manpower Log.
