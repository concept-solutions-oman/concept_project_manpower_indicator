Quick Installation & Usage

1
Install the module directly from your Odoo Apps menu.
2
Open the Employees module to view the dashboard and floating panel.
3
Click On Duty via the top status indicator to start a work session.
4
Click Off Duty to end the work session.
5
Review activity safely under Reporting → Manpower Log.
