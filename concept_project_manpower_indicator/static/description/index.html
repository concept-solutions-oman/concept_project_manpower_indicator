Quick Installation

Up and running in minutes

1Install the module from the Odoo Apps menu.

2Open the Employees module to see the dashboard and floating panel.

3Click On Duty via the status indicator to start a work session.

4Click Off Duty to end the work session.

5Review activity under Reporting → Manpower Log.
